# Basquete — Página Web Estática

Projeto individual de Desenvolvimento Web I (DWI), desenvolvido por Davi Gehart.

## Tema
O site apresenta informações sobre basquete, incluindo sua origem, fundamentos,
regras básicas e algumas curiosidades.

## Tecnologias
- HTML5
- CSS3

O projeto não utiliza JavaScript, frameworks ou temas prontos.

## Publicação
O site foi estruturado para ser publicado no GitHub Pages.

## Estrutura
- `index.html` — página principal
- `style.css` — folha de estilos
- `README.md` — documentação do projeto
